# Focus

Input: $ARGUMENTS

Cut to what matters most.

- **A question** → the direct answer in 1–3 sentences; a caveat only if it changes the answer.
- **A task list, plan or problem** → the single most important thing to do now, why, and the very next concrete action. Everything that can wait goes in one line.
- **A document or draft** → its core message in one sentence, and a list of what to cut.
- **Empty input** → apply this to the current conversation: what is the one thing to do next?

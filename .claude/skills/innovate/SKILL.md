# Innovate

Challenge: $ARGUMENTS

1. **Usual answers** — the 3 obvious approaches, one line each, set aside.
2. **Reframe** — the assumptions behind the challenge, questioned; the problem restated 2–3 different ways.
3. **Generate** through these lenses: first principles (what is actually required?), analogies from other industries, SCAMPER (substitute, combine, adapt, modify, put to other use, eliminate, reverse), technology shifts, and the customer's unmet need.
4. **Concepts** — 3–5 new ideas. For each: what it is, what makes it new, feasibility (low / med / high), the main risk, and a cheap experiment to test it within a week.
5. **Recommendation** — the one to test first.

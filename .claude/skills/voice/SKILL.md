# Voice

Input: $ARGUMENTS

First pin down the voice:
- **Voice described** ("warm and reassuring", "confident brand voice", "like a friendly doctor") → turn it into 4–5 concrete traits: sentence length, vocabulary, formality, warmth, humour, use of "you" and "we".
- **Samples given** → analyze them and list the traits to match: typical words, sentence rhythm, punctuation habits, openings and closings.
- **No voice given** → ask for a description or a sample.

Then write the content in that voice, with the facts unchanged. End with the trait list, so the user can reuse it as a voice guide.

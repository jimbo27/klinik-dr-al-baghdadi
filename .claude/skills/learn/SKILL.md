# Learn

Topic: $ARGUMENTS

Teach the topic so it sticks:

1. **One-line idea** — what it is, in plain words.
2. **Simple explanation** — as for a smart beginner, with an everyday analogy.
3. **How it works** — the key parts or steps, from basic to deeper.
4. **Example** — one worked, concrete example (code, numbers or a real case).
5. **Common mistakes** — 2–3 misconceptions to avoid.
6. **Check yourself** — 3 short questions, with answers given when the user asks.
7. **Next** — what to learn after this.

Match the depth to the user's level when they state it or it shows in the conversation, and offer to go deeper on any part.
